# 📦 物品收纳管家

**🌐 线上地址（手机安装用）：<https://hjyyayayaya.github.io/home-inventory/>**
（扫码见 `github-pages-qr.png`；手机 Chrome 打开 → 出现「安装应用」→ 安装后离线可用）
仓库：<https://github.com/hjyyayayaya/home-inventory> · 本地更新代码后重新上传即可同步线上

一个**纯本地**的家庭物品库存与保质期管理小应用，动物森友会（动物岛）风格的可爱界面。
无需安装、无需联网、数据不出你的设备。

界面风格参考开源组件库 [animal-island-ui](https://github.com/guokaigdg/animal-island-ui)
的设计规范（薄荷绿主色、奶油纸底色、暖棕文字、大圆角、3D 像素阴影、Nunito 圆体），
用纯 CSS 复刻，因此不需要 React / Node 环境。
（联网时会加载 Google Fonts 的圆体字体；离线时自动回退到系统字体，功能不受影响。）

## 功能

- **物品台账**：名称、分类、存放位置、数量、单位、购买日期、保质期至、最低库存、备注
- **保质期管理**：自动计算剩余天数，分「正常 / 临期 / 已过期」三色标记，临期天数可自定义（默认 7 天）
- **库存管理**：一键 +/− 调整数量；设置「最低库存」后，数量不足会自动标记「库存不足」
- **概览仪表盘**：物品总数、临期、过期、库存不足统计；分类统计与位置分布图
- **查找**：关键词搜索（名称/分类/位置/备注）+ 状态/分类/位置筛选 + 多种排序
- **数据备份**：导出 JSON 备份（可再导入恢复/合并）、导出 CSV（Excel 可直接打开）
- 手机浏览器也能用（响应式布局）

## 如何使用

### 方式一：直接打开（最简单）

双击 `index.html`，用浏览器（推荐 Chrome / Edge）打开即可。

### 方式二：双击 `start-app.bat`（推荐，可用手机访问）

会自动启动本地服务并在浏览器打开 `http://localhost:8765`。
手机连同一个 Wi-Fi，访问 `http://你电脑的IP:8765` 也能用（电脑 IP 可用 `ipconfig` 查看）。

### 方式三：安装成桌面 APP（长期使用推荐）⭐

本项目是一个 PWA（渐进式 Web 应用），可以像普通软件一样安装到电脑上：

1. 先双击 `start-app.bat` 启动服务；
2. 用 **Edge** 或 **Chrome** 打开 `http://localhost:8765`；
3. 点击地址栏右侧出现的 **「安装」图标**（或菜单 → 应用 → 将此站点作为应用安装）；
4. 确认后，开始菜单 / 桌面会出现 **「物品收纳管家」** 图标，和普通软件一样点开即用。

安装后的效果：

- **独立窗口运行**，没有地址栏和标签页，就是一个桌面软件的样子；
- **完全离线可用**（Service Worker 已缓存全部程序文件，断网、不开服务器都能打开）；
- **关闭重开数据不丢**：数据保存在浏览器的本地数据库（LocalStorage）中，
  并已在启动时申请「持久化存储」，不会被系统随意清理；
- 想卸载：Edge 菜单 → 应用 → 右键「物品收纳管家」→ 卸载，干净利落。

> 注意：安装的桌面 APP 与浏览器标签页的数据**互相独立**（各自一份 LocalStorage）。
> 如果之前在浏览器里记过账，在 APP 里用「导入」功能迁移一下即可。

### 安卓手机上使用 📱

**支持「安装应用」的浏览器：Chrome、Edge**（vivo / 小米 / OPPO / 华为等手机自带浏览器
不支持 PWA 安装，只用它们打开会看到页面里的提示条）。以 vivo 手机为例：

1. 在 vivo 应用商店搜索安装 **Microsoft Edge**（或 Chrome）；
2. 用 Edge 打开 <https://hjyyayayaya.github.io/home-inventory/>；
   （网址可用微信发给自己，或扫项目里的 `github-pages-qr.png`）
3. 菜单 → **添加到主屏幕 / 安装应用**，确认后桌面出现应用图标；
4. 从桌面图标点开就是全屏独立应用，**离线可用**。

页面本身也会自动检测：用不支持的浏览器打开时，顶部会出现提示条告诉你该怎么做。

> 用自带浏览器直接访问也能正常记账（数据存在该浏览器里），只是没有
> 「安装成 App」和离线能力 —— 想要完整体验请用 Chrome / Edge 打开一次并安装。

**局域网直连（备用方案）**：GitHub 访问慢时，可让手机和电脑连同一 Wi-Fi，
电脑双击 `start-app.bat`，手机扫 `phone-qr.png` 直接访问电脑上的版本
（打不开就双击 `allow-phone-access.bat` 放行防火墙）。

手机端的几点说明：

- **关于数据存在哪**：安卓的规则是所有 App（原生 App 和安装后的 PWA 一样）
  的数据本体都放在系统分配的应用沙盒里，不允许指向任意文件夹。
  你能**完全自选位置**的是备份文件：
  - 「**分享备份**」按钮（手机端自动出现）：调出系统分享面板，可以把备份
    存到文件管理器的任意目录、微信收藏、网盘等任何地方；
  - 「导出备份」：保存到 Chrome 的下载目录；在 Chrome 设置 → 下载里开启
    「下载前询问保存位置」后，每次导出都可以自己选目录（含 SD 卡）；
  - 「导入」：可以从手机上的任意位置选择备份文件恢复/合并。
  - 建议：养成每周「分享备份」到微信收藏或网盘的习惯，换手机也不怕。
- 手机的数据和电脑的**各自独立**（分别存在各自浏览器的本地数据库里）。
- 建议在路由器里给电脑**固定 IP**（DHCP 静态绑定）：电脑 IP 一变，手机上
  原来保存的数据会「找不到」（数据还在旧地址名下，改回 IP 就回来了）。
- 局域网地址是 http:// 开头的非加密源，Chrome 不允许在这种地址上开启离线缓存
  和正式的「安装应用」。想让手机**离线可用、随处可用**：把整个文件夹原样上传到
  任一免费 HTTPS 静态托管（GitHub Pages / Netlify / Vercel 等），手机 Chrome
  访问时就会出现「安装应用」，装完完全离线可用，程序文件一行都不用改。

### 开始记账

第一次打开是空的，可以：

1. 点击右下角 **＋** 添加真实物品；或
2. 点击 **「载入示例数据看看」**，先体验功能，之后随意修改或删除。

## 数据保存在哪里？会不会丢？

数据保存在**当前浏览器的 localStorage** 里（不联网、不上传）。

注意两点：

- 数据跟「浏览器 + 打开方式」绑定：一直用同一个浏览器、同一种方式打开即可。
  （用 `start-app.bat` 打开的记录、安装的桌面 APP、直接双击 `index.html` 打开的记录，
  是互相独立的三份。）
- **新增 / 编辑 / 数量调整 / 删除**的每一步都会立刻写入本地数据库，
  打开页面时自动读取历史数据，刷新或重开都在。
- **清浏览器缓存/站点数据会把记录清掉**，建议养成习惯，偶尔点右上角「导出备份」存一份 JSON 文件。

换电脑 / 换浏览器迁移：旧环境「导出备份」→ 新环境「导入」即可（按物品 ID 合并，重复的会被导入版本覆盖）。

## 常用技巧

- 「保质期至」填到期日即可，剩余天数自动算；不填表示该物品无保质期（如被褥、工具）。
- 「最低库存提醒」填一个数（如 2），当数量 ≤ 2 时会显示粉色「库存不足」标记，概览里也会计数。
- 概览里的「⏰ 临期提醒 / 已过期 / 库存不足」彩色卡片可以直接点，会跳到列表并自动筛好。
- 临期默认提前 7 天，在概览的「保质期提醒」面板里可改。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，单文件夹、零依赖、无构建步骤。
- **PWA**：`manifest.json`（应用信息与图标）+ `sw.js`（离线缓存）。
  更新了程序文件后，把 `sw.js` 里的 `home-inventory-v1` 版本号 +1 即可刷新客户端缓存。
- 数据持久化用 LocalStorage（浏览器自带的本地数据库，键 `homeInventory.items.v1`）：
  数据模型是一个物品数组，结构简单，按「简单数据优先 LocalStorage」的原则没有引入 IndexedDB；
  启动时会调用 `navigator.storage.persist()` 申请持久化。
- `app.js` 里数据模型就一个数组（`id/name/category/location/quantity/unit/purchaseDate/expiryDate/minStock/note/...`），想扩展很容易。
- `style.css` 顶部集中定义了主题 CSS 变量（颜色/圆角/阴影），想换配色改一处即可。
- `serve.py` 局域网启动器：自动探测电脑 IP、生成手机扫码用的 `phone-qr.png`；
  `allow-phone-access.bat` 一键放行 Windows 防火墙（供手机访问）。
- `make-icons.py` 用于重新生成 PWA 图标（需要 Pillow，`python make-icons.py`）。
